🌸 Гидролаты для сухой и зрелой кожи

Питающие, увлажняющие душистые воды. Омолаживают, восстанавливают, подходят для увядающей кожи.

Гидролат жасмина

Jasminum grandiflorum
🌸 Аромат: яркий цветочный
Действие:
  • Успокаивает кожу, снимает покраснения
  • Стабилизирует эмоции
Показания:
  • Используется для ухода anti-age
  • Для создания кремов
  • Обладает ярким ароматом, подходит для ароматизации волос

Гидролат иланг-иланга

Cananga odorata
🌸 Аромат: яркий цветочный
Действие:
  • Увлажняет и балансирует кожу
  • Оказывает успокаивающее действие на психику
Показания:
  • Используется для ухода anti-age
  • Для создания кремов
  • Обладает ярким ароматом, подходит для ароматизации волос

Гидролат ладана

Boswellia carterii
🌳 Аромат: бальзамический
Действие:
  • Оказывает противовоспалительное действие на кожу
  • Омолаживающее действие
  • Балансирует смешанную кожу
Показания:
  • Можно использовать для ухода за волосами

Гидролат нероли

Citrus aurantium var. amara
🍊 Аромат: сильный цветочный
Действие:
  • Оказывает сильное увлажняющее действие на кожу
Показания:
  • Уход за возрастной кожей
  • Можно использовать как парфюм

  • Стабилизирует эмоции
Показания:

  • Подходит для ухода за любой кожей

Гидролат розового дерева

Aniba rosaeodora
🌳 Аромат: мягкий древесно-цветочный
Действие:
  • Успокаивает кожу, увлажняет, омолаживает
  • На психику оказывает стабилизирующее эмоции действие
  • Улучшает качество сна
Показания:
  • Подходит для ухода за любой кожей

Гидролат шиповника

Rosa canina
🌹 Аромат: нежный, розовый
Действие:
  • Омолаживающее действие
  • Увлажняет и балансирует, выравнивает
  • Успокаивает психику
Показания:
  • Уход за сухой и возрастной кожей
💡 Как использовать гидролаты:

Гидролаты — это мягкие средства, которые можно применять в чистом виде. Распыляйте на лицо после очищения, используйте как тоник, добавляйте в кремы и маски, ополаскивайте волосы после мытья.
